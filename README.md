# 🚀 RBX Launcher v3.1

Современный, лёгкий и полностью автономный кастомный лаунчер (bootstrapper) для **Roblox** на Windows в стиле Bloxstrap, написанный на Python (`CustomTkinter` + `Pillow`).

---

## ✨ Основные возможности

* **⚡ Управление графикой и FastFlags:**
  * Тонкая настройка уровня графики (от 1 до 10), громкости и `Shift Lock` напрямую через `GlobalBasicSettings_13.xml`.
  * Разблокировка FPS (60, 120, 144, 240 или произвольное значение), отключение пост-обработки (`PostFX`), отображение счётчика FPS и выбор рендера (`Direct3D 11`, `Vulkan`, `OpenGL`).
  * Готовые пресеты в один клик: *Производительность*, *Баланс* и *Качество*.
* **🎨 Кастомизация клиента (с автоматическим бэкапом):**
  * **Звуки:** замена любых звуковых файлов игры (`.wav`, `.mp3`, `.ogg`) с возможностью мгновенного отката к оригиналам.
  * **Шрифты:** изменение шрифта внутри самой игры Roblox (`.ttf`, `.otf`), а также настройка шрифта и масштаба интерфейса самого лаунчера.
  * **Курсоры:** 6 встроенных векторных пресетов (*Классика*, *Чёрный*, *Неон*, *Прицел*, *Точка*, *Минимал*) или загрузка собственного `.png`.
  * Автоматическое определение обновления версии Roblox и переустановка всех ваших модов одной кнопкой.
* **🎮 Библиотека игр и профили:**
  * Добавление любимых плейсов по ссылке или `Place ID` с автоматической загрузкой названий и иконок через официальное API Roblox.
  * История недавних запусков, сохранение пользовательских профилей настроек, экспорт и импорт конфигурации в `JSON`.
* **🖼 Встроенная графика:**
  * Иконка приложения, баннеры и пресеты курсоров генерируются программно — лаунчер не требует внешних папок с ресурсами.

## 🛠 Установка и запуск из исходного кода

Если вы не хотите запускать готовый `.exe`, вы можете запустить лаунчер напрямую через Python:

1. Убедитесь, что у вас установлен **Python 3.10+**.
2. Установите необходимые библиотеки:
   ```bash
   pip install customtkinter pillow
   ```
3. Скачайте файл `RBXLauncher.py` и запустите его:
   ```bash
   python RBXLauncher.py
   ```

## 🔒 Безопасность и срабатывание антивирусов

> **Почему Защитник Windows может ругаться на `.exe` файл?**
> Скомпилированный файл создан с помощью `PyInstaller` и не имеет платной цифровой подписи издателя. Антивирусы часто выдают ложное срабатывание (*False Positive*) на любые неподписанные Python-программы, которые изменяют файлы в папке `AppData\Local\Roblox`. 
> 
> Исходный код полностью открыт — вы можете проверить каждую строчку в этом репозитории и собрать `.exe` самостоятельно.
